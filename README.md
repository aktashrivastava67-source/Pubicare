# Pubicare – Puberty Health Analysis

Pubicare is a Streamlit-based educational application designed to help users understand puberty and track basic health information.

## Features

* BMI calculator and interpretation
* Menstrual cycle tracking and estimated next period date
* Acne photo journal
* Puberty and hormone education
* Healthy habit suggestions
* Doctor guidance and personal records

## Technologies Used

* Python
* Streamlit
* Pandas
* Pillow

## How to Run Locally

1. Install Python.

2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## Disclaimer

Pubicare is an educational student project, not a medical diagnostic tool. Do not enter real or sensitive health information into this prototype.
